## About This Lab
This lab covers basic computer system identification, disk structures, partition analysis and file system identification. It also explores the PC boot process and the importance of system evidence in digital forensics.

## Activities Covered
- System identification and storage information collection.
- Mapping digital evidence to system layers.
- Understanding programs, processes and threads.
- Disk sector and partition size calculations.
- Safe partition table inspection using PowerShell, Disk Management and Kali Linux.
- Comparing MBR and GPT partitioning methods.
- Explaining the PC boot process and identifying UEFI boot mode.
- Identifying NTFS, FAT32, ext4 and swap file systems.
- Verifying partition sizes using sector information.

## Tools Used
- Windows 11
- Windows PowerShell
- Command Prompt
- Kali Linux
- Disk Management
